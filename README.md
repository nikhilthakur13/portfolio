# Nikhil Thakur Advanced Portfolio — V2

This version is based on the information in Nikhil Thakur's resume and is intentionally self-contained: the portfolio UI, responsive CSS, animations and JavaScript are all inside `index.html`.

## Run locally
- Open the `site` folder in VS Code.
- Open `index.html` with Live Server for the full PWA experience.
- Opening `index.html` directly also renders the UI because CSS and JavaScript are embedded.

## Deploy
Upload the entire `site` folder to Vercel, Netlify, GitHub Pages, or another HTTPS static host. Do not upload only `index.html` if you want PWA installation; keep `manifest.webmanifest`, `sw.js`, and `assets/` with it.
